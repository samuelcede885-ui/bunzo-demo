# Bunzo Burgers (demo)

Demo de concepto de una hamburguesería **ficticia**: scroll cinematográfico, hamburguesa desmontable y menú interactivo.

- `index.html`: la web lista para GitHub Pages, en un solo archivo.
- `proyecto/`: código fuente (React + Vite + Tailwind + GSAP + Lenis). Ejecútalo con `npm install` y luego `npm run dev`.

Marca, productos, sucursales y horarios son ilustrativos.
